# 🍽️ Food Recipes Website

A simple recipe website built using **HTML** as a practice project to improve my web development skills.

## 📖 About

This project contains a homepage and multiple recipe pages. It is part of my journey to learn the fundamentals of web development by building small projects.

## ✨ Features

* Home page with recipe navigation
* Individual pages for each recipe
* Clean and simple HTML structure
* Beginner-friendly project organization

## 🛠️ Built With

* HTML5

## 📂 Project Structure

```
.
├── index.html
├── recipes/
│   ├── butter_chicken.html
│   ├── chickpea_curry.html
│   └── fish_curry.html
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone git@github.com:aditya-rai08/odin-recipes.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No installation or dependencies are required.
